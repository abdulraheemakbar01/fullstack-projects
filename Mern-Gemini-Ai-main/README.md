# ☆ MERN Stack Project with Gemini AI Integration

This is a full-stack application where users can sign up and log in to interact directly with Gemini AI. The project is designed to provide a seamless and secure chat experience with real-time AI responses.

## 🛠 Tech Stack

• Frontend: React.js (Vite), Tailwind CSS, Axios.
• Backend: Node.js, Express.js.
• Database: MongoDB Atlas.
• AI: Google Gemini API.
• Security: JWT, Cookie-parser,.
