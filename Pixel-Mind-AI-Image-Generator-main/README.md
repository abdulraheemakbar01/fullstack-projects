# ☆ Pixel Mind – AI Image Generator & Community Platform

Pixel Mind is a high-performance full-stack web application that transforms text prompts into stunning AI-generated images. Users can create, download, and share their masterpieces in a public community gallery.

## 🛠 Tech Stack

Frontend: React.js, Tailwind CSS, Axios.
Backend: Node.js, Express.js (MVC Architecture).
Database: MongoDB Atlas.
AI Engine: Cloudflare AI Models.
Cloud Storage: Cloudinary (Media management).
